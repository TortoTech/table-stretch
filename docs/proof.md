# 最小高度表格布局的形式化模型与证明

## 1. 定义及前提

表格有 `m ≥ 1` 行、`n ≥ 1` 列，无跨行/跨列单元格。容器宽度 `W`，固定横向空间 `G`，可分配宽度 `B = W-G ≥ 0`。所有尺寸为非负整数；每列宽度至少为 1。

列 `j` 的上界为 `u_j`。给定列下界及所有单元格最小可容纳宽度的最大值记为 `l_j`。单元格高度曲线 `h_ij(w)` 在定义域内是完整、非增、分段常数的阶梯函数，最后一个断点之后不变。每个高度值都必须来自能完整容纳内容的排版。

可行域及目标为：

\[
F_= = \{w\in\mathbb N^n: l_j\le w_j\le u_j,\ \sum_j w_j=B\},
\qquad H(w)=\sum_{i=1}^m\max_{j=1}^n h_{ij}(w_j).
\]

先求松弛宽度域 `F_≤`（将等号改为 ≤）的最优解。固定纵向间距只给目标加常数，可以在算法外处理。

**前提边界**：若真实引擎存在未建模断点、宽度相关字体变化、跨格耦合或高度非单调行为，此模型的证明不能转移到该引擎。量化单位只保证量化模型的最优性。

## 2. 词序列曲线

`from_tokens` 输入正词宽 `a_1,...,a_t`、非负固定词间距 `g`、正固定行高 `L`。每行是一个连续词区间，区间宽度为词宽之和加内部间距；不允许拆词，无强制换行。

**引理 1（贪心断行）**：从左到右每行放入最多可容纳词的策略，使行数最小。

证明：归纳比较任意可行断行。贪心第一行结束位置不早于该方案。若前 `k` 行结束位置不早于该方案，则方案第 `k+1` 行在贪心尚未放置的词中所包含的部分是其一个后缀；由于词宽和间距非负，这个后缀仍放得下一行。因此贪心第 `k+1` 行结束位置也不早。若某方案用 `q` 行放完，贪心至多用 `q` 行。证毕。

宽度增加时原断行仍可行，所以最优行数非增。从最长词宽开始，对首次高度下降的宽度作整数二分查找，直到一行宽度。每次找到紧邻当前平台的下一个断点，故得到完整曲线。空内容定义为宽度至少 1、高度 0。代码的算术范围错误会返回 `Overflow`。

## 3. 断点集的完备性

令 `C_j` 为 `l_j` 和列中所有单元格在 `(l_j,u_j]` 内的断点并集；大于 `B` 的候选不可能被使用，可以删除。

**引理 2**：任意 `w ∈ F_≤` 都存在 `c ∈ ∏C_j ∩ F_≤`，使 `H(c)=H(w)`。

证明：令 `c_j` 为 `C_j` 中不大于 `w_j` 的最大值。因 `l_j≤w_j`，它存在；且 `l_j≤c_j≤w_j≤u_j`。在 `(c_j,w_j]` 内没有任何列内曲线的断点，故对全部 `i` 都有 `h_ij(c_j)=h_ij(w_j)`。求行最大值再求和不变，而总宽度不增加。证毕。

所以候选集合上的精确最优值等于完整 `F_≤` 的最优值，并非对原目标作近似。

## 4. 状态与支配

处理完前 `k` 列的状态为 `s=(b,v,p)`：`b` 为已用总宽度；`v_i=max_{j≤k} h_ij(p_j)`；`p` 为列宽路径。初始 `b=0,v_i=0`。

同一层上定义 `a ≼ b` 当且仅当 `a.used≤b.used` 且对每一行 `a.v_i≤b.v_i`。路径不参与比较。

加入下一列候选 `c` 时，状态转移为：

\[
T_c(s).used=s.used+c.width,\qquad
T_c(s).v_i=\max(s.v_i,c.height_i).
\]

**引理 3（支配保持）**：若 `a≼b`，则任意相同候选 `c` 都满足 `T_c(a)≼T_c(b)`。

证明：加同一非负宽度保持 ≤；`max(x,z)` 对 `x` 单调。证毕。由归纳，相同的任意后缀也保持支配。因此任何能使 `b` 满足宽度预算的后缀，都能使 `a` 满足预算，且 `a` 的最终总行高不大于 `b`。

**推论**：可安全删除被支配状态；相同状态可以去重。只比较总高度不足以建立这个引理。

## 5. 前沿不变量和全局最优性

每层保留前沿 `P_k`。令 `A_k` 为不剪支配状态的完整候选枚举，在同样的预算限制下处理前 `k` 列所得的状态集。保持两个不变量：

1. 可行性：`P_k ⊆ A_k`。
2. 覆盖性：每个 `s∈A_k` 都存在 `p∈P_k`，使 `p≼s`。

基例为初始零状态。归纳步：根据引理 3，扩展保留状态能覆盖扩展完整状态。插入新状态时，若旧状态支配它，旧状态即可覆盖它；否则删除新状态支配的旧状态，并保留新状态。支配关系具有传递性，删除操作不丢失覆盖性。保留状态均来自真实转移，所以可行性也保持。

Rust 另外用 `used + Σ剩余列最小宽度 > B` 提前删枝。该条件下任何后缀都超预算，所以只删除无可行完整延伸的前缀，不影响最终解。Lean 版本只使用当前宽度预算过滤，没有编码这一加强剪枝。

**定理 1**：完整求解结束，选择 `P_n` 中总行高最小的状态 `p*`，则它在所有候选宽度组合上全局最优。

证明：任意完整候选状态 `s` 都被某个 `p∈P_n` 支配。于是 `H(p*)≤H(p)≤H(s)`。又 `p*` 自身可行。证毕。结合引理 2 得到在 `F_≤` 上最优。

算法先比较总高度，再以已用宽度选择平局解；此平局规则不改变高度最优性，但不承诺最终列宽具有其他审美目标的全局最优性。

## 6. 拉伸填满保持最优

必要且充分的宽度可行条件是 `l_j≤u_j` 且 `Σl_j≤B≤Σu_j`。

取定理 1 的解 `w*`。设余量 `D=B-Σw*_j`。因为 `Σ(u_j-w*_j)≥D`，可以在不超过列上限的情况下增加列宽，得到 `w'≥w*`、`Σw'_j=B`。算法批量均摊余量；每个非终止循环至少分配一个单位，有剩余时必有未达上限的列，因此终止。

曲线非增给出 `H(w')≤H(w*)`。而 `w'∈F_=⊆F_≤`，由 `w*` 最优又有 `H(w*)≤H(w')`。故两者相等。

**定理 2（最终结果）**：成功返回的拉伸布局在 `F_=` 上全局最优，并满足所有宽度约束。上界不足时返回不可行，而非违反上界强行拉伸。

## 7. 终止、复杂度与失败

每列候选有限，列数有限；全部搜索与支配比较有限。设每列最多 `K` 个候选、运行中前沿最多 `P` 个状态，则简单线性支配扫描约为 `O(n K P² m + n² K P)` 时间，前沿和路径约 `O(P(m+n))` 空间，另有 `O(m Σ|C_j|)` 候选高度存储。`P` 最坏可指数增长。

词曲线生成最多 `t` 个平台，每次二分调用线性断行计算，保守界 `O(t² log U)`，`U` 为单行宽度。搜索限制不保证候选预处理的内存/时间上界。

代码在计数限制处返回错误，不返回近似布局；无论 debug/release 都不依赖整数回绕。此证明的“成功”不包括进程内存耗尽、外部终止或编译器/硬件故障。

## 8. 机器检查覆盖范围

`proof/Optimality.lean` 固定 Lean 4.19.0，只依赖 Std。

| Lean 定理 | 内容 |
| --- | --- |
| `extend_mono`, `cost_mono` | 状态转移和目标对支配关系单调 |
| `insert_covers`, `prune_covers` | 支配剪枝保留覆盖性 |
| `prune_subset`, `run_subset` | 保留状态来自完整枚举，可行性不凭空产生 |
| `expand_covers`, `run_covers` | 预算过滤、逐列搜索保持覆盖性 |
| `global_optimality` | 前沿内取最小者属于完整枚举，且不劣于任意完整枚举解 |
| `stretch_preserves_optimum` | 可行且不增加行高的拉伸保持最优值 |

`global_optimality` 以“已选到前沿中的最小元素”为参数；Rust 的线性最小值选择实现尚未在 Lean 中逐行验证。Lean 使用任意自然数，行高函数的前 `m` 项参与求和；Rust 使用有限向量和显式范围检查。Lean 的剪枝是递归列表定义，Rust 是在线插入，二者使用相同支配不变量，但没有机器检查二者的 refinement。

机器检查没有 `sorry` 或自定义公理。`#print axioms` 显示最优性定理仅依赖 Lean 标准逻辑中的 `propext`、`Classical.choice`、`Quot.sound`；拉伸定理不依赖公理。

断点完备性、词曲线生成、后缀预算剪枝及具体 Rust 实现的对应关系由本文的数学论证和独立穷举测试支持，**不属于已经完成的端到端机器验证**。
